## Nima uchun ikkita serif

Instrument Serif'da **kirill alifbosi YO'Q**. Usiz rus tilidagi
sarlavhalar `▯▯▯▯` bo'lib ko'rinardi.

Playfair Display butun kirill alifbosini va o'zbek tilining `ʻ`
belgisini qamrab oladi. U `fontFamilyFallback` sifatida beriladi:

* lotin matn — Instrument Serif (dizayndagi asl ko'rinish);
* kirill matn — Playfair Display.

Sarlavhalar bir tilda bo'lgani uchun aralash qator amalda uchramaydi.
