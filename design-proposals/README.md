# NFCSTORE — 4 ta vizual dizayn taklifi (prototiplar)

**Bu papka production'ga ulanmagan.** `src/`, `public/` va Worker'ga tegmaydi, Vite build'ga kirmaydi, hech qanday API chaqirmaydi. Faqat statik HTML/CSS/JS.
