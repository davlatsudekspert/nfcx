# NFCSTORE V2

Independent Flutter application for the new NFCSTORE design.

Safety:
- Existing mobile/ remains untouched.
- Website/backend/database remain untouched.
- V2 communicates only through existing API endpoints.
- Preview package is separate from the Play Store app.
- App Links stay disabled for preview builds.

Themes:
1. Editorial Ivory: warm ivory, graphite, restrained champagne.
2. Midnight Navy Gold: deep navy, muted gold, warm white.

Design direction:
Premium digital identity platform. No legacy orbital decoration, heavy gold borders,
lightning, or copied legacy layout.
