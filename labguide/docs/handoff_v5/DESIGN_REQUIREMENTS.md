# LabGuide — Code uchun topshiriq

Avval mavjud repository va uning ko‘rsatmalarini o‘qing. Ishlayotgan loyihani almashtirmang. Ushbu paketdagi prototype.html interaktiv UX namunasidir. Uning ekranlarini ishlab chiqarishga mos komponentlar, routing va holat boshqaruvi bilan amalga oshiring. Native loyiha hali yo‘q bo‘lsa, Flutter iOS/Android ilovasi tavsiya qilinadi; mavjud texnologiya bo‘lsa undan foydalaning.

1. UZ/RU/EN lokalizatsiya, system/light/dark mavzu, email OTP, mehmon preview, shifokor/laborant/student/ustoz rollari. OTP demo va production adapterlari ajratilsin. Production kod serverda tekshiriladi, muddati va urinish limiti bo‘ladi.
2. Beshta tab: Bosh, Tahlillar, Lab, Kutubxona, O‘rganish. Har bir tab navigation stackini saqlasin. Profil yuqori burchakda. iOS/Android safe area, keyboard inset va system back bilan ishlasin.
3. Scroll ko‘tarilganda katta sahifa sarlavhasi va yordamchi matn ixcham toolbar holatiga o‘tsin. Pastga qaytganda kengaysin. Pastki navigatsiya qoladi: foydalanuvchi bo‘limlarga kirishni yo‘qotmaydi. 12–16 px hysteresis qo‘llang, tebranish bo‘lmasin. 180–220 ms yumshoq transition; reduced-motion rejimida animatsiya o‘chsin. Ilovaning butun masshtabini kichraytirmang. Inline prototip bu scroll harakatini namoyish qilmaydi: uni native buildda alohida yarating va tekshiring.
4. Tahlil kartasi: nima uchun, metodga bog‘liq reference interval, birliklar, yuqori/past natijaga ta’sir qiluvchi omillar, specimen/preanalitika, cheklovlar, manba/reviewer/date. Hali tasdiqlanmagan content draft bo‘lsin. Natijadan avtomatik tashxis chiqarmang.
5. Instrument workflow: manufacturer/model/reagent REF/IFU revision/calibrator lot. Aniq mos tasdiqlangan IFU bo‘lmasa parametr bermang. HUMAN reagent IFU apparat qo‘llanmasi bilan bir hujjat emas. Service kodlari va xavfsizlikni o‘chiruvchi yechimlar kiritilmasin.
6. QC, preanalytics, microscopy, dilution calculator, bookmarks, offline packs, research outline, books va source metadata ekranlari. Micrograph va kitob uchun foydalanish huquqi tekshirilsin. User PDF yuborgani umumiy tarqatish huquqi emas.
7. Teacher mini tizim: class create/invite/revoke, question bank, assignment draft/publish/deadline/timer/feedback release, student join/submit/own result, teacher own-class summary/item analysis. Server role/class membershipni har so‘rovda tekshirsin. Students boshqa studentlarning natijalarini ko‘rmaydi. Barcha submissions serverda bir marta va ishonchli vaqt bilan saqlanadi. Offline topshirish bo‘lsa conflict va deadline siyosati aniq bo‘lsin. Avval kichik MVP: guruh, assignment, submission, results; videochat va katta LMS shart emas.
8. Freemium + monthly/yearly Pro taklifi. Narxlarni config/store productdan oling, prototype ichida qat’iy narx yo‘q. Xarid, pending, cancelled, expired, refund, restore, offline entitlement holatlarini alohida yarating. StoreKit/Google Play server verification va notifications ishlating. Restore eski tranzaksiyani boshqa LabGuide hisobga o‘z-o‘zidan ko‘chirmasin; account recovery yordam yo‘li bo‘lsin.
9. Device policy taklifi: 1 hisob/2 faol qurilma. Qurilmalarni ko‘rish va eski qurilmani chiqarish. Email OTPning o‘zi account sharingni to‘liq to‘xtatmaydi. Server sessionlar va qisqa muddatli signed offline entitlement; lokal shifrlash va watermark ommaviy tarqatishni kamaytiradi, 100% to‘sishni va’da qilmang. Device IDni install key bilan yarating, shaxsiy hardware fingerprint yig‘mang. Bepul kontentni obuna tugaganda bloklamang.
10. Accessibility: kamida44 px target,16px input,11px dan kichik matn yo‘q; large font, screen reader, keyboard, kontrast va rangsiz status. 320/390/430 px phone hamda tablet. No horizontal overflow, long RU text va keyboardda primary action yo‘qolmasin.

Ishni bosqichma-bosqich yakunlang: design tokens/components → onboarding/navigation → content screens → teacher mini MVP → billing/offline adapters. Backend yo‘q joyda aniq labelled demo adapter ishlating; funksiyani ishlayapti deb ko‘rsatmang. Har milestone build va meaningful tests bilan tekshirilsin. Oxirida o‘zgargan fayllar, tekshiruv, hali ulanmagan xizmatlar va ishga tushirish buyruqlarini yozing.

## Premium dizayn — vizual talab

Kuchli editorial sans tipografika (39/30/25/16/14/11px), warm ivory/forest/lime, tactile3Dglass molecular hero, kam border,27pxhero/23pxcards/18pxbuttons. Tasvir dekorativ, aniq molekula yoki klinik mikrofoto emas. Bir rasmni hamma klinik kartaga takrorlamang; role/category-specific assetlar yarating. Light/dark crop va readabilityni saqlang. Button press160ms, page transition200ms; reduced motionga rioya qiling. Faqat sahifa rasmi emas, haqiqiy ishlaydigan native komponentlar bo‘lsin.
