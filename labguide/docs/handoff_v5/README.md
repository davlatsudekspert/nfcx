# LabGuide — Code Starter v5

## Siz uchun
1. ZIPni Claude Code ishlayotgan loyiha papkasiga oching.
2. START_HERE.md matnini Code chatiga bering yoki shu faylni o‘qib bajarishini ayting.
3. prototype.html — brauzerda ochiladigan interaktiv dizayn. Internet UI uchun shart emas; manba havolalari internet bilan ochiladi.
4. Mehmon sifatida kirish yoki email shakli → demo kod 123456 → rol tanlash.
5. Profil orqali rol va mavzuni o‘zgartiring; yuqorida UZ/RU/EN; bosh sahifada glyukoza kartasini oching.

## Paket
- START_HERE.md — asosiy bajariladigan topshiriq.
- prototype.html — mustaqil brauzer prototipi, ichiga hero rasm joylangan.
- DESIGN_REQUIREMENTS.md — batafsil ekran/UX talablari.
- PRODUCT_PLAN.md — qamrov, bosqichlar, demo chegaralari.
- CONTENT_MODEL.json — kontent yozuvi uchun namuna; klinik jihatdan tasdiqlangan baza emas.
- molecular-hero.webp — dekorativ original asset.
- QA_REPORT.md — tekshirilgan va hali tekshirilmagan holatlar.
